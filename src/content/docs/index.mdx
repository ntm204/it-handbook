## Đang gặp sự cố

Chọn triệu chứng để xem cách xử lý. Lệnh bên dưới là thứ nên chạy đầu tiên.

<div class="hb-grid">
  <a class="hb-card" href="xu-ly-su-co/#su-co-1"><span class="t">Một máy không vào được mạng</span><code>ipconfig /all</code></a>
  <a class="hb-card" href="xu-ly-su-co/#su-co-2"><span class="t">Cả khu mất mạng, mạng chậm bất thường</span><code>show interfaces status</code></a>
  <a class="hb-card" href="xu-ly-su-co/#su-co-6"><span class="t">Tài khoản domain bị khoá liên tục</span><code>Search-ADAccount -LockedOut</code></a>
  <a class="hb-card" href="xu-ly-su-co/#su-co-4"><span class="t">Không vào được thư mục chia sẻ</span><code>{"Test-NetConnection <server> -Port 445"}</code></a>
  <a class="hb-card" href="xu-ly-su-co/#su-co-5"><span class="t">Máy in không in</span><code>{"ping <ip-máy-in>"}</code></a>
  <a class="hb-card" href="xu-ly-su-co/#su-co-7"><span class="t">Server Linux đầy ổ</span><code>df -h && df -i</code></a>
  <a class="hb-card" href="xu-ly-su-co/#su-co-8"><span class="t">Server chậm</span><code>uptime</code></a>
